# 양식별 개인정보 항목표 (1-2 초안)

- 근거: 1-1 추출 결과 `assets/forms/extracted/forms/*.txt` + 쪽별 PNG (`pages/page_XX.png`)
- 상태: **확정 (2026-11-08)** — 사용자 확인 완료, 결정 사항은 맨 아래 "결정 기록"
- 라벨은 PLAN.md 3장 체계. `—`는 마스킹 대상 아님 (근로조건·고정 문구)
- `(employer)` 등 괄호 안은 라벨 JSON의 `owner`. **사업주 쪽 라벨에는 모두 `owner: employer`** → 마스킹 정책으로 따로 켜고 끔
- **참고 항목**(`attributes`): 라벨은 없지만 위치를 기록하는 값 (`relation`, `age`, `nationality`, `emergency_relation`). 평가에서 여기 걸린 탐지는 중립
- **하드네거티브**(`negatives`): 양식 안에서 개인정보처럼 보이지만 아닌 값 (회사 대표번호). 가리면 오탐
- 기입 형태: **텍스트**(인쇄/손글씨 여부는 합성 단계에서 문서·필드별로 뽑음 — 4단계), **체크**(`□`, `[ ]`, `( )`, `○표`), **서명란**(서명·도장·지장 — 4단계 축 1·2)
- 양식 문구: 값 바로 앞의 고정 문구 → 규칙 팩 "양식 키" 초안으로 사용

개인정보가 아닌 기입 항목 (라벨 `—`, 합성 때 값은 채움):
- 근로개시일·근로계약기간(날짜), 근무장소(참고 항목 `workplace_address` — 주소 형태로 적히는 경우가 많음), 업무의 내용(직종), 소정근로시간·휴게시간, 근무일/휴일, 임금지급일, 계약일(`년 월 일`)
- 체크: 상여금·기타급여 있음/없음 `( )`, 지급방법 `( )`, 사회보험 `□` 4개, 월(일·시간)급 `○표`(건설일용·단시간)
- 임금 금액(월급·상여금·기타급여·제수당·시간외/야간/휴일 수당) → `SALARY` (준식별, 마스킹 정책으로 켜고 끔)

문서별 차이:
- `minor` 8번: `가족관계기록사항에 관한 증명서 제출 여부:`, `친권자 또는 후견인의 동의서 구비 여부 :` → 텍스트(예: "제출", "구비"), 라벨 —
- `minor` 12번: "13세 이상 15세 미만인 자 … 취직인허증" 고정 문구 (값 없음)
- `construction_daily` 6번: `기타 제수당(시간외․야간․휴일근로수당 등): 원(내역별 기재)` + `․시간외 근로수당: 원(월 시간분)` 등 3줄 → `SALARY`. 가운뎃점이 `․`(U+2024)
- `part_time` 4번: 요일별 근로시간 표(6열: 요일·근로시간·시업·종업·휴게) → 라벨 —, 표 셀 기입 연습용. 5번 `초과근로에 대한 가산임금률: %`

규칙 팩에 반영할 점 (9단계):
- 앵커 문구 목록: `(서명)`, `(인)`, `(서명 또는 인)`, `(signature)` — PLAN 1장 예시의 `서명:`은 이 양식들에 없음
- 소속 키워드에 **`사용자`, `Employer`, `Employee`** 추가 필요 (PLAN 1장 예시는 "사업주·대표자"만)
- 국내 양식은 소속 키워드가 앵커와 **같은 줄이 아님** → 탐색 범위는 같은 줄 왼쪽 + **앵커 위 최소 2~3줄**, 그 안에서 가장 가까운 소속 키워드 채택 (못 찾으면 소속 미상 → 가림). `대 표 자`는 사업주 쪽 보조 키워드로 사용 가능
- 사업주 서명란·사업주 쪽 span은 `owner: employer` → 정책 기본값: 대표자 이름·휴대전화 가림, 법인 인감(사업주 서명란) 안 가림
- 국내 양식 사업주 서명란은 `(서명)` 하나뿐이지만 실제로는 법인 인감이 찍히는 자리 (축 2 법인 인감 60%)

## 결정 기록 (2026-11-08)

- **Q1. 사업주 쪽 칸** — 사업체명·사업장 주소는 라벨 없음. 회사 전화는 대표번호면 하드네거티브(`negatives`), 휴대전화면 `PHONE`. 대표자·사용자 성명은 `NAME`. 사업주 쪽에서 나온 라벨에는 모두 `owner: employer` → 규칙 팩 마스킹 정책으로 사업주 쪽만 따로 켜고 끔. **기본값: 대표자 이름·휴대전화 가림, 법인 인감 가리지 않음**
- **Q2. 라벨 체계에 없는 항목** — 새 라벨을 만들지 않음. 관계·만 나이·국적·비상연락처 관계는 라벨 JSON `attributes`(참고 항목)에 위치 기록. 평가에서 여기 걸린 탐지는 중립(정탐도 오탐도 아님)
- **Q3. 배분** — 5절 표대로
- **Q4. 단위** — 문서 기준 100건. 처리 시간은 쪽당·문서당 둘 다 보고
- **표본 수** — 텍스트 1,000건은 정형 라벨별 span 최소 500개 목표 (A에도 회사 추가 항목을 확률적으로), 이미지 100건은 비율 유지
- **서명란** — 소속 키워드 탐색 범위는 앵커 위 최소 2~3줄
